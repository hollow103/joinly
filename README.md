# Joinly SDD

Documentacion de producto y arquitectura para Joinly, una aplicacion movil de eventos cercanos.

El nombre es provisional hasta comprobar disponibilidad de marca, dominio y usuarios en plataformas relevantes.

El proyecto se organizara como monorepo con `mobile/`, `backend/`, `admin/` y `docs/`. Durante esta fase solo se mantiene documentacion; no se implementara codigo hasta cerrar las especificaciones.

## Flujo de trabajo

1. Responder `docs/00-cuestionario-inicial.md`.
2. Completar los documentos en el orden numerico.
3. Convertir los casos de uso priorizados en especificaciones implementables.

No se implementara codigo hasta aprobar el alcance del MVP y sus criterios de aceptacion.
